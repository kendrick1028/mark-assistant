mark

한 사람이 자기 자신을 위해 만든 개인 비서 앱
A personal assistant app built by one person for their own use

무엇을 하나요

  • mark는 개발자 본인만 사용하는 개인용 앱입니다. 일반에 공개하거나 판매하지 않습니다.
  • 사용자가 텔레그램으로 요청하면, 사용자 본인의 Google 캘린더, Gmail, Google 드라이브에서 필요한 일을 합니다: 일정 확인과 추가, 메일 검색과 요약, 답장 초안 작성, 파일 찾기와 정리.
  • 메일 보내기, 휴지통으로 옮기기, 일정 삭제, 초대, 파일 공유처럼 되돌리기 어려운 작업은 매번 사용자의 승인을 받은 뒤에만 실행합니다.

What it does

  • mark is a personal app used only by its developer. It is not offered to the public or sold.
  • When the user asks through Telegram, it works with the user's own Google Calendar, Gmail and Google Drive: checking and adding events, searching and summarizing email, drafting replies, finding and organizing files.
  • Actions that are hard to undo, such as sending email, moving items to trash, deleting events, sending invitations and sharing files, run only after the user approves each one.
