mark

개인정보처리방침

시행일: 2026년 9월 29일

1. 누가 사용하나요

mark는 개발자 본인 한 사람만 사용하는 개인용 앱입니다. 다른 사람의 정보를 수집하기 위한 서비스가 아닙니다.

2. 어떤 정보에 접근하나요

사용자가 Google 로그인 화면에서 허용한 범위 안에서 사용자 본인의 Google 캘린더 일정, Gmail 메일, Google 드라이브 파일에 접근합니다.

3. 어디에 쓰나요

사용자 본인이 요청한 일을 처리하는 데에만 씁니다: 일정 관리, 메일 검색과 요약, 답장 초안 작성, 파일 검색과 정리. 광고, 판매, 사용자 프로필 판매에는 쓰지 않습니다.

4. 어떻게 처리하고 어디에 저장하나요

요청을 처리하는 데 필요한 내용(예: 요약할 메일 본문)은 AI 모델 제공자인 Anthropic의 API로 전송되어 처리됩니다. 인증 토큰과 작업에 필요한 최소한의 메모는 사용자가 관리하는 컴퓨터의 비공개 계정에만 저장되며, 별도의 외부 서버에 보관하지 않습니다.

5. 다른 곳에 제공하나요

Google 사용자 데이터를 판매하지 않으며, 위의 AI 모델 처리 외에는 제3자에게 제공하지 않습니다.

6. Google API 서비스 사용자 데이터 정책

mark가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

7. 연결 해제와 삭제

언제든 Google 계정의 서드파티 앱 및 서비스에서 mark의 접근을 해제할 수 있습니다. 해제하면 mark는 더 이상 Google 데이터에 접근할 수 없고, 저장된 인증 토큰은 사용자가 관리하는 컴퓨터에서 삭제할 수 있습니다.

Privacy Policy

Effective September 29, 2026

Who uses it. mark is a personal app used only by its developer. It is not a service for collecting other people's data.

What it accesses. Within the permissions the user grants on the Google sign-in screen, it accesses the user's own Google Calendar events, Gmail messages and Google Drive files.

How it is used. Only to carry out the user's own requests: managing events, searching and summarizing email, drafting replies, finding and organizing files. It is never used for advertising or sold.

Processing and storage. Content needed to handle a request, such as an email to summarize, is sent to the API of Anthropic, the AI model provider, for processing. Authentication tokens and minimal working notes are stored only in a private account on a computer the user manages, not on a separate external server.

Sharing. Google user data is not sold and is not shared with third parties other than the AI model processing described above.

Google API Services User Data Policy. mark's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time under Third-party apps and services in the Google Account. After that, mark can no longer access Google data, and stored tokens can be deleted from the user's computer.
